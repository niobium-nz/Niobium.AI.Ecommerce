# Synthetic contract examples

input.json is invented data, including URLs, IDs, costs and tax/fee assumptions.
It is not a real product, current tax advice or a reachable approved reference board.
The example uses explicit none to demonstrate unambiguous zero tax/fees, not a
recommended policy. Tax/fee percentages in real inputs need their actual bases.

The tests create structural strategy/profile/image mocks from the actual skill
schemas. Those mocks test orchestration, not marketing quality or visual inspection.
For substantive complete examples, use each unchanged skill's own examples with
its disclaimers. Do not use a fixture's existence as approval or evidence.
