# Claude Cowork setup

This is portable source, not a prebuilt native Claude plugin. Use the currently
supported project/folder-instruction or plugin workflow in the target account;
agent.yaml is descriptive metadata. Preserve AGENT.md and all relative resources.
Install the three complete bundled skills without changing their contracts.

Bind a real headed interactive browser and screen inspection with the profiler's
scope/cleanup safeguards. An HTTP fetch or JavaScript scraper is not equivalent.
Bind board pixel reading and a stable handoff location, trusted UUID/lossless JSON,
and Google Drive exact lookup, folder creation, raw JSON upload and full verification.
Do not assume a default Drive connector is writable or copying ChatGPT namespaces
will work. Verify actual tool schemas and permissions before a run.

Configure candidates_folder_id, and board_handoff_binding only when local board
inputs need a trusted same-content durable URL. The caller owns product approval;
no council integration or new approval field is inferred. Retain host approvals and
limit writes to prescribed candidates paths. Exclude purchases, ads, website launch,
image generation, sharing and deletion. No browser login or unrelated sessions.

Test the host-acceptance checklist before any separately authorized live smoke
test. The package does not claim one-click cross-vendor import, successful native
packaging or a completed Cowork deployment. Runtime need not execute Python.
