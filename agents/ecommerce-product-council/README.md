# Product Council reference implementation

See [architecture](../../docs/product-council-sourcing-approval.md). The Python standard-library module `council.py` implements deterministic five-specialist synthesis, one-winner selection, sourcing evidence handoff and evidence-bound human authorization. Run `cd agents/ecommerce-product-council && python -m unittest -v`. Specialist research, supplier integrations, persistence, human-review UI and production onboarding wiring are not yet implemented.
