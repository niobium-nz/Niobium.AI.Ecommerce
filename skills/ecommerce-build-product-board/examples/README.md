# Fictional examples

The JSON files demonstrate accepted contracts only. They contain fictional file
paths, attachment names and reserved example-domain URLs. No example photos are
included, fetched or claimed to exist. No example output image is supplied because
no real product photographs were provided for this build.

- `input.mixed.json`: all three source types with strict coverage and selected views.
- `input.paths.json`: a simple path list without a wrapper.
- `input.supported-views-only.json`: explicit acceptance of incomplete coverage;
  hidden sides still must not be invented.
- `error.json`: source access failure, not a placeholder successful board.
- `behavioral-cases.json`: text-only review scenarios with expected behavior;
  these are not automated visual tests or evidence of actual editing quality.
