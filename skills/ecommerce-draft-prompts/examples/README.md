# Synthetic examples

All product facts, names, claims of hypothetical merchant verification, economics,
segments and reference locations in these examples are fictional test data. No
reference board is bundled and no image pixels were inspected to create them.
The example HTTP domain is intentionally non-resolving. The local path is a
placeholder; replace it with a file actually accessible to the executing host.
Running the examples unchanged does not authorize a successful visual inspection.

- `input.local.json` and `input.url.json` are complete contract examples. They
  contain the same finalized market strategy, with different board locators.
- `output.json` illustrates three well-formed successful prompts, conditional on
  an actual board matching the fictional verified fixture context. It is not a
  live execution result.
- `output.explicit-ratio.json` illustrates a 9:16 variant for a separate input
  that explicitly requests 1080 by 1920. It is not the default output for the
  square hero in `input.local.json`.
- `output.empty.json` is for a separate valid, board-inspected strategy containing
  no supported still opportunity, not a shortcut for inaccessible input.
- `output.needs-clarification.json` and `output.error.json` show the two blocker
  paths.
- `scenarios.json` records expected behavior for 30 synthetic cases. These are
  review fixtures, not evidence of live model, browser or image-generation tests.

The downstream producer must get the actual reference image separately. The
compact output deliberately does not carry a URL/path or claim to have produced
any final image. No image variants or image files are generated by this skill.
